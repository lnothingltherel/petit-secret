# Petit Secret pour Alicia — version modifiable

## Ouvrir le site
1. Décompresse `petit-secret-alicia.zip`.
2. Ouvre le dossier.
3. Double-clique sur `index.html` pour voir le site dans ton navigateur.
4. Pour modifier les textes, ouvre `js/script.js` ou `index.html` avec un éditeur de texte.
5. Pour modifier les couleurs et le style, ouvre `css/style.css`.

## Publier les changements sur GitHub Pages
Si tu veux remplacer le site en ligne, téléverse les fichiers du projet dans le dépôt GitHub `petit-secret` en conservant les dossiers `css` et `js`.

## À savoir sur le questionnaire
Cette version prépare les réponses et permet de les copier, mais elle ne les envoie pas automatiquement à ton adresse. Pour recevoir les réponses à distance, il faut connecter un service de formulaire ou un petit serveur. Ne mets pas de mot de passe ni de clé privée dans le JavaScript public.
